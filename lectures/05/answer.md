## 宿題

- 取り組んだレベル：実装
- やったこと（変更したファイル・設定・処理、または設計した取得方法）：
  - `app/retrieval.py` に `add_neighbor_pages()` と `search_with_neighbors()` を追加した。ベクトル検索でヒットした各ページについて、`load_pages()` のページ情報から同じ `document_id` の前後ページ（PDFページ番号 ±1）を探し、ヒットしたページの直後に「前→後」の順で付け足す
  - 同じページは1回だけ返す（ヒット同士が隣り合う場合や、後で別のヒットとして出てくるページは、隣として重複させない）。資料（document_id）の境界はまたがない
  - 隣のページには距離を付けず、`retrieved_by: "neighbor"` と `neighbor_of`（どのヒットの隣か）を付け、講義番号・PDFページ番号などの引用情報も一緒に返す
  - `app/config.py` に `RAG_NEIGHBOR_WINDOW`（環境変数 `AIE_RAG_NEIGHBORS`、既定 0）を追加し、`app/tools.py` の `search_materials` から使う。0 なら変更前とまったく同じ結果になるので、同じコードのまま `AIE_RAG_NEIGHBORS=0`（変更前）と `=1`（変更後）を切り替えて比べられる。Graph の入口検索は変更していない
  - `tests/test_neighbors.py`（APIキー不要）で、前後ページの追加・重複なし・資料境界・0のとき変わらないことを確認（`uv run pytest` 27件すべて成功）
  - 本文と埋め込みの設定は変えていないので、索引は作り直していない
